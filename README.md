# VK BOT Marketing — AI-маркетинг-консультант в ВКонтакте

AI-бот для **первичного маркетингового аудита** и консультаций внутри ВКонтакте.  
Может быть встроен в процессы **маркетинговых агентств** и **отделов маркетинга компаний**: структурированный опрос, анализ, выводы, рекомендации и PDF-отчёт.

> Фокус продукта — режим **маркетинг-консультанта**: аудит рыночного положения, маркетинговых активностей, посадочных страниц и unit-экономики.

## Для кого

- маркетинговые агентства (аудит клиентов на входе / discovery);
- in-house отделы маркетинга и growth-команды;
- владельцы бизнеса и CMO, которым нужен быстрый первичный срез;
- консультанты, которые хотят стандартизировать интервью и отчётность.

## Что умеет

### Маркетинг-консультант
- аудит текущего рыночного положения;
- аудит маркетинговых активностей и каналов;
- аудит посадочных страниц / оффера / CTA;
- рекомендации с опорой на unit-экономику (CAC, LTV, ROMI и др.).

### Первичный аудит (автосценарий)
- 10 вопросов по блокам: стратегия, цифры, клиенты, продукт, процессы;
- формат **1 вопрос → 1 ответ**;
- по завершении: анализ, выводы, рекомендации;
- автоматическая генерация и отправка **PDF-отчёта** в чат VK.

### Платформа бота
- многодиалоговость (создание / переименование / переключение / удаление);
- режимы общения (помощник, программист, преподаватель, бизнес, маркетинг, собеседник);
- краткосрочная память (до 100 сообщений на диалог, JSON);
- клавиатуры VK на русском языке;
- Gemini через [ProxyAPI](https://proxyapi.ru/).

## Стек

| Компонент | Технология |
|-----------|------------|
| VK API | VKBottle |
| LLM | Google GenAI SDK + ProxyAPI (Gemini) |
| Хранение | JSON (`users/`) |
| PDF | fpdf2 |
| Конфиг | `.env` + `python-dotenv` |

## Быстрый старт

```bash
git clone https://github.com/PavelKoff2025/VK_BOT_Marketing.git
cd VK_BOT_Marketing

python3 -m venv venv
source venv/bin/activate   # macOS / Linux
pip install -r requirements.txt

cp .env.example .env
# заполните VK_TOKEN и PROXY_API_KEY
```

В настройках сообщества VK:
1. Long Poll API — включить;
2. события: входящие сообщения;
3. права бота: сообщения (+ документы для PDF).

Запуск:

```bash
python3 main.py
# или
python3 -m bot
```

## Переменные окружения

См. `.env.example`:

- `VK_TOKEN` — токен сообщества;
- `PROXY_API_KEY` / `PROXI_API_KEY` — ключ ProxyAPI;
- `GEMINI_MODEL` — модель (например `gemini-2.5-flash`);
- `PROXYAPI_GOOGLE_BASE_URL` — `https://api.proxyapi.ru/google`.

**Не коммитьте `.env`** — там секреты.

## Как провести первичный аудит в боте

1. Нажмите **🔍 Первичный аудит** (или напишите `аудит`).
2. Ответьте на 10 вопросов по одному.
3. Получите текстовый анализ + PDF во вложении.
4. При необходимости отмените опрос кнопкой **❌ Отменить аудит**.

## Структура проекта

```
bot/            # handlers VK, меню, аудит, PDF
config/         # settings, режимы, 10 вопросов аудита
services/       # AI, диалоги, память, аудит-флоу, PDF
models/         # User / Dialog / Message
storage/        # JSON-хранилище
keyboards/      # клавиатуры VK
users/          # данные пользователей (runtime)
reports/        # временные PDF
assets/fonts/   # шрифт для кириллицы в PDF
```

## Интеграция в бизнес-процесс агентства / отдела маркетинга

Типовой сценарий:

1. Клиент / внутренний заказчик пишет боту в VK.
2. Бот проводит стандартизированный discovery-аудит (10 вопросов).
3. Команда получает единый PDF с анализом и приоритетами.
4. Консультант углубляет гипотезы в режиме «Маркетинг-консультант».

Так бот закрывает рутину первичного сбора и ускоряет выход к рекомендациям.

## Безопасность

- секреты только в `.env`;
- диалоги пользователей не попадают в git (`users/*.json`);
- PDF после отправки удаляется с диска.
