# Документы для сдачи задания

Скриншоты бота кладите в папку:

```text
Docs/screenshots/
```

## Рекомендуемые имена файлов

| Файл | Что на скрине |
|------|----------------|
| `01-vk-api-settings.png` | Настройки сообщества VK (Long Poll / API) |
| `02-vk-token-masked.png` | Токен доступа (**середина скрыта**) |
| `03-main-menu.png` | Главное меню бота |
| `04-dialogs-list.png` | Список диалогов |
| `05-marketing-mode-reply.png` | Ответ в режиме «Маркетинг-консультант» |

Допустимы форматы: `.png`, `.jpg`, `.jpeg`, `.webp`.

## Важно

- Не публикуйте полный `VK_TOKEN` и ключи ProxyAPI.
- После добавления файлов сделайте коммит и push в GitHub, если скрины должны быть в репозитории.
