## 1. Что сделано по заданию преподавателя (базовая часть)

Реализован AI-бот на **Python + VKBottle** с интеграцией LLM через **ProxyAPI** (Google GenAI SDK, модель **gemini-3.1-flash-lite**).

- многодиалоговый режим (создание, список, переименование, удаление, переключение);
- краткосрочная память до 100 сообщений, хранение в JSON (`users/`);
- режимы общения со своими system prompt (помощник, программист, преподаватель, бизнес, маркетинг, собеседник);
- меню и клавиатуры VK на русском;
- асинхронность, обработка ошибок, fallback при сбоях API;
- конфигурация через `.env`, README, MIT-лицензия, `.gitignore`.

## 2. Собственное развитие под задачу маркетинга

Добавлен профиль **🎯 Маркетинг-консультант** под практику аудита:

- рынок / позиционирование;
- маркетинговые активности;
- посадочные страницы;
- unit-экономика и рекомендации.

**Автосценарий «Первичный аудит»:**

- 10 вопросов из методики первичного маркетингового аудита (стратегия → цифры → клиенты → продукт → процессы);
- формат «один вопрос — один ответ»;
- по итогам: анализ, выводы, рекомендации;
- автоматическая генерация и отправка **PDF-отчёта** в чат VK.

Бот ориентирован на внедрение в **маркетинговые агентства** и **отделы маркетинга** как инструмент стандартизированного discovery/аудита.

## 3. Демонстрация
